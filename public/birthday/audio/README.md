# Music player audio

Drop your playlist files here as mp3s and name them:

- `track-1.mp3`
- `track-2.mp3`

…or point the `src` of each track at any URL you own.

Edit the playlist (titles, artists, file names / links) in one place:
`src/lib/birthday/config.ts` → `MUSIC.playlist`.

Audio never autoplays — it only starts after the listener taps play.
